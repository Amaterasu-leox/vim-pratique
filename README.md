# Vim Pratique

Mes exercices pour apprendre à utiliser Vim sous Ubuntu.

## Ce que je pratique

- JavaScript avec Node.js
- Python
- HTML
- CSS
- Fichiers de configuration Linux
- Création et modification de fichiers avec Vim

## Objectif

Apprendre à utiliser Vim directement dans le terminal et progresser en programmation.

## Environnement

- Ubuntu
- Vim
- Node.js
- Python 3
